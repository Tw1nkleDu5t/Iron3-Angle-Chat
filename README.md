# Iron3-Angle-Chat

一个基于 Java Socket 的轻量级即时通讯系统，支持群聊、私聊、文件传输和昵称管理。

---

## 项目简介

Iron3-Angle-Chat 是一款基于 Java Socket 编程的轻量级即时通讯系统。它采用经典的 C/S 架构，通过自定义文本协议进行通信，支持多客户端同时在线聊天、文件传输和用户管理。

无论是用于学习 Java 网络编程，还是搭建一个简单的内部沟通工具，Iron3-Angle-Chat 都能满足你的需求。

---

## 核心功能

| 功能 | 说明 |
|:----:|:------|
| 群聊 | 向所有在线用户发送消息，实时交流 |
| 私聊 | 指定目标用户进行一对一私密聊天 |
| 文件传输 | 支持发送和接收文件（Base64 编码传输） |
| 昵称管理 | 用户可以自定义昵称，便于识别 |
| 在线列表 | 实时显示在线用户及其昵称 |
| 历史记录 | 自动保存聊天记录和接收的文件 |
| 双模式客户端 | 支持 GUI 图形界面和命令行控制台模式 |
| 断线重连 | 服务器异常断开后自动清理资源 |

## 快速开始

### 环境要求

| 组件 | 版本要求 |
|:----:|:--------:|
| JDK | 11 或更高版本 |
| 操作系统 | Windows / macOS / Linux |

### 一分钟安装指南

**步骤 1：克隆仓库**

```
git clone https://github.com/Tw1nkleDu5t/Iron3-Angle-Chat.git
cd Iron3-Angle-Chat
```

**步骤 2：编译代码**

```
# 创建输出目录
mkdir -p out

# 编译所有源文件
javac -d out src/main/java/client/*.java src/main/java/common/*.java src/main/java/server/*.java
```

**步骤 3：启动服务器**

```
java -cp out server.Server
```

服务器默认监听端口：`8000`

**步骤 4：启动客户端**

打开新的终端窗口，启动 GUI 客户端：

```
java -cp out client.Client
```

或启动控制台客户端：

```
java -cp out client.Client --console
```

```

```

#### 控制台命令

| 命令 | 格式 | 说明 |
|:----:|:----:|:----:|
| 群聊 | `输入任意消息` | 直接输入文字发送给所有人 |

| 修改昵称 | `/nick 新昵称` | 修改自己的昵称 |
| 退出 | `/quit` | 退出聊天 |

```
- /quit：退出聊天

[系统] I3A账号 Bob 已上线。
[私聊] 小波 -> 你: 在吗？
```

```
                       |

```

### 消息协议

消息格式：`TYPE|sender|target|content`

| TYPE | 说明 |
|:----:|:----:|
| LOGIN | 用户登录 |
| LOGOUT | 用户登出 |
| MESSAGE | 群聊消息 |
| PRIVATE | 私聊消息 |
| FILE | 文件传输 |
| NICKNAME | 昵称修改 |
| USERS | 在线用户列表 |
| SYSTEM | 系统消息 |

## 常见问题

### Q1: 连接服务器失败怎么办？

可能原因及解决方法：

| 原因 | 解决方法 |
|:----:|:--------:|
| 服务器未启动 | 先启动服务器端程序 |
| 端口被占用 | 检查 8000 端口是否被其他程序占用 |
| IP 地址错误 | 确认服务器 IP 地址是否正确 |
| 防火墙拦截 | 允许 Java 程序通过防火墙 |

### Q2: 如何修改服务器端口？

修改 `Server.java` 中的端口配置：

```java
private int port = Integer.getInteger("server.port", 8000);
```

修改为其他端口（如 8080）：

```java
private int port = Integer.getInteger("server.port", 8080);
```

客户端连接时填写对应端口即可。

### Q3: 文件保存在哪里？

| 数据类型 | 保存路径 |
|:--------:|:--------:|
| 聊天记录 | `历史聊天记录/chat_history.txt` |
| 接收的文件 | `历史聊天记录/received_files/` |

### Q4: 支持多人同时在线吗？

支持。服务器使用多线程处理每个客户端连接，可以同时支持多个用户在线聊天。

### Q5: 如何查看在线用户列表？

- GUI 客户端：在线用户会自动显示在聊天对象下拉框中
- 控制台客户端：登录后服务器会自动推送在线用户列表

### Q6: 昵称和账号有什么区别？

| 字段 | 说明 |
|:----:|:----:|
| I3A 账号 | 唯一身份标识，用于登录和系统识别 |
| 昵称 | 显示名称，用于聊天时展示，可以随时修改 |
